# RC Planner

**Цифровой полевой помощник авиамоделиста и FPV-пилота.**
Подготовка → сборы → проверка → полёт → посадка → разбор → обслуживание → следующий полёт.

Работает офлайн · ставится на домашний экран · ничего не отправляет наружу

</div>

---

## Что это

Локальный персональный инструмент авиамоделиста. Не облачный сервис, не соцсеть
и не CRM: приложение живёт у вас в кармане и работает даже посреди поля без интернета.

> Simple outside. Powerful inside.
> The user's data belongs to the user.

## Что внутри

| Раздел | О чём |
|---|---|
| **Сегодня** | Экран дня в четырёх состояниях с подсветкой следующего шага: дома — панель готовности (флот, АКБ, погода сейчас), прогноз из кэша, «Перед выездом» (сборы, АКБ на зарядку, регламент) и «К вылету»; на поле — подготовленный борт с кнопкой «Взлёт»; в полёте — живой таймер; вечером — разбор дня |
| **Флот** | Борта с фото, паспортом, компонентами (мотор, ESC, FC, RX, GPS, сервы, VTX — с версией прошивки) и статусом: Готов · Проверить · Обслуживание · Полёты запрещены. Карточка борта — сегменты «Обзор · Компоненты · Обслуживание · История». Здесь же аккумуляторы: циклы растут сами после каждого полёта |
| **Полёт** | Предполётный чек-лист по типу борта (FPV квад, самолёт, крыло), экран полёта в стиле HUD с кольцом до сигнала таймера («время на аккумулятор»: вибрация и звук), незасыпающий экран, «Посадка» и итог полёта |
| **Журнал** | Полёты по дням с фильтром по борту и статистика: календарь лётных дней, налёт по месяцам, бортам и локациям, итоги полётов, износ АКБ; печать и CSV — в меню |
| **Ещё → Сборы** | Наборы «что взять с собой»: выезд на поле, FPV-сессия, ремонт — и свои; прогресс виден на «Сегодня» |
| **Ещё → Инструменты** | Ссылки на официальные web-конфигураторы, прошивки (в том числе список версий Walksnail), калькуляторы, погоду и документацию |
| **Ещё → Локации** | Запомненные места полётов с координатами и мини-картой; основная подставляется в полёт и прогноз |
| **Ещё → Шаблоны** | Свои чек-листы поверх встроенных; ни один пункт не обязателен: ок / проблема / пропуск |
| **Ещё → Данные** | Экспорт/импорт/резервная копия — один локальный файл `.rcpilot`; экспорт отдельного борта со всей историей; дата последней копии |
| **Ещё → Приватность** | Честный список online-функций и что именно уходит по каждой |
| **Окна для полётов** | Борт → место → дата: прогноз Open-Meteo из «Сегодня», окна по ТТХ борта (ветер и высота полёта), день одной полоской из 24 часов; online-функция по нажатию |
| **Обслуживание** | Журнал ремонтов, замен, прошивок и осмотров в карточке борта; открытые работы меняют статус, регламент напоминает об осмотре |
| **Конфигурации** | CLI dump, diff и файлы прошивок с версиями и сравнением «что изменилось» |

### Тема и три режима интерфейса

По умолчанию тема — как в системе (тёмная ночью, светлая днём, если так
настроен телефон); в «Ещё → Настройки» её можно закрепить: тёмная или
светлая. Там же — режим интерфейса:

- **В перчатках** — для поля: всё крупно и контрастно, только главное,
  без фона и анимаций;
- **Стандарт** — спокойный вид «Кокпит», мягкая подсветка следующего шага,
  экономнее к батарее;
- **Максимум** — по умолчанию: живой фон, стеклянные карточки, неоновые
  рамки у главного.

На любом экране подсвечена ровно одна кнопка — следующий шаг. Переходы между
экранами анимированы; системная настройка «уменьшить движение» их выключает.

## Приватность: данные не собираются

Приложение не собирает данные — ни о вас, ни о ваших моделях, ни о том, как вы
им пользуетесь. Это не обещание в политике, а устройство программы: собирать некуда.

- **Нет сервера и аккаунтов.** Страница отдаётся как статические файлы.
- **Нет аналитики, счётчиков, внешних шрифтов и картинок.** Сборка падает, если
  в ней остаётся хоть один внешний ресурс — это проверяет `build.js`.
  В фоне наружу уходит только запрос обновления самой страницы; online-функции
  (прогноз, карта, поиск места) работают строго по нажатию, а координаты
  для прогноза огрубляются до ~1 км. Точная геопозиция не покидает устройство.
- **Что хранится:** модели с фото, компоненты, полёты, чек-листы, сборы,
  обслуживание, конфигурации и файлы прошивок, батареи, локации, настройки.
- **Где хранится:** в IndexedDB браузера на вашем устройстве. Лёгкие настройки
  (тема, режим интерфейса, номер прочитанного выпуска) — в localStorage.
- **Вибрация и звук сигнала таймера** — локальные функции телефона
  (Vibration API и Web Audio): ничего не записывают и никуда не отправляют.
- **Экспорт и импорт** — обычный JSON-файл (`.rcpilot`), который вы сохраняете
  и переносите сами. На телефоне файл предлагается через системный лист
  «Поделиться»: куда его положить — решаете вы, приложение само никуда его
  не отправляет. Если копии не было две недели, «Сегодня» напомнит.
- **Удаление** стирает данные с устройства; копий нигде нет — восстановить их
  сможет только ваш файл резервной копии.
- **Раздел «Инструменты»** — ссылки на сторонние официальные сайты; они
  открываются в браузере и помечены значком «online».

## Как поставить на телефон

1. Откройте адрес приложения в браузере.
2. **iPhone:** Safari → «Поделиться» → «На экран „Домой“».
   **Android:** Chrome → меню → «Установить приложение».

Дальше приложение открывается во весь экран и **без интернета**.
При первом запуске — приветствие в три шага, на «Сегодня» — «Начало работы»
из пяти шагов. Подробное руководство по каждому экрану — «Ещё → Инструкция»
в приложении (кнопка «?» в шапке экрана ведёт в его раздел) или тот же текст
файлом: [`docs/user-guide.md`](docs/user-guide.md).

Вариант без хостинга: `dist/rc-planner.html` — один файл со всем внутри,
открывается двойным кликом откуда угодно.

## Разработка

```bash
npm run setup   # npm install + браузер для тестов (один раз)
npm run icons   # пересобрать иконки из SVG (нужен sharp)
npm run build   # public/ (PWA) и dist/rc-planner.html (офлайн-файл)
npm test        # семь наборов: данные, картинки, аудит экранов, офлайн-файл, PWA, вёрстка, экраны с данными
npm run release # build + test
npm run art:check # проверка картинок assets/art (ТЗ — docs/art-brief.md)
```

В рантайме зависимостей нет: vanilla HTML/CSS/JS на современной платформе
браузера — View Transitions, `@layer`, `@property`, OKLCH для экранов P3,
container/`:has()`, popover, Wake Lock, Web Share. Код — модули `src/NN-*.js`,
стили — `styles/NN-*.css` по слоям; сборка склеивает их в один HTML с
CSP-хэшами скриптов. Свой promise-wrapper над IndexedDB (`db.js`).
Справочный контент отделён от логики и лежит в `data/`. Фон и картинки —
отдельная задача: слоты в `assets/art/slots.json`, ТЗ — `docs/art-brief.md`.
Правила работы над проектом — в [`AGENTS.md`](AGENTS.md), планы — в [`ROADMAP.md`](ROADMAP.md).
