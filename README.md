# RC Planner

**Цифровой полевой помощник авиамоделиста и FPV-пилота.**
Подготовка → сборы → проверка → полёт → результат → обслуживание → следующий полёт.

Работает офлайн · ставится на домашний экран · ничего не отправляет наружу

</div>

---

## Что это

Локальный персональный инструмент авиамоделиста. Не облачный сервис, не соцсеть
и не CRM: приложение живёт у вас в кармане и работает даже посреди поля без интернета.

> Simple outside. Powerful inside.
> The user's data belongs to the user.

## Что внутри

| Раздел | О чём |
|---|---|
| **Сегодня** | Статус флота, кнопка «Начать полёт», открытое обслуживание, последние полёты |
| **Флот** | Модели с фото, паспортом, компонентами (мотор, ESC, FC, RX, GPS, сервы, VTX…) и статусом: Готова · Проверить · Обслуживание · Полёты запрещены |
| **Полёт** | Предполётный чек-лист по типу модели (FPV квад, самолёт, крыло), Flight Session с таймером, итог полёта и журнал |
| **Чек-листы** | Встроенные шаблоны + свои; ни один пункт не обязателен: ок / проблема / пропуск |
| **Сборы** | Наборы «что взять с собой»: выезд на поле, FPV-сессия, ремонт — и свои |
| **Обслуживание** | Журнал ремонтов, замен, прошивок и осмотров; открытые работы меняют статус модели |
| **Конфигурации** | CLI dump, diff и файлы прошивок с версиями и сравнением «что изменилось» |
| **Аккумуляторы** | Парк батарей; циклы растут сами после каждого полёта |
| **Локации** | Запомненные места полётов, основная подставляется в полёт |
| **Инструменты** | Ссылки на официальные конфигураторы (Betaflight, INAV, ExpressLRS, EdgeTX), прошивки, калькуляторы и документацию |
| **Данные** | Экспорт/импорт/резервная копия — один локальный файл `.rcpilot`; экспорт отдельной модели со всей историей |

## Приватность: данные не собираются

Приложение не собирает данные — ни о вас, ни о ваших моделях, ни о том, как вы
им пользуетесь. Это не обещание в политике, а устройство программы: собирать некуда.

- **Нет сервера и аккаунтов.** Страница отдаётся как статические файлы.
- **Нет аналитики, счётчиков, внешних шрифтов и картинок.** Сборка падает, если
  в ней остаётся хоть один внешний ресурс — это проверяет `build.js`.
  Единственный сетевой запрос — проверка обновления самой страницы.
- **Что хранится:** модели с фото, компоненты, полёты, чек-листы, сборы,
  обслуживание, конфигурации и файлы прошивок, батареи, локации, настройки.
- **Где хранится:** в IndexedDB браузера на вашем устройстве. Лёгкие настройки
  (тема, номер прочитанного выпуска) — в localStorage.
- **Экспорт и импорт** — обычный JSON-файл (`.rcpilot`), который вы сохраняете
  и переносите сами. Приложение его никуда не отправляет.
- **Удаление** стирает данные с устройства; копий нигде нет — восстановить их
  сможет только ваш файл резервной копии.
- **Раздел «Инструменты»** — ссылки на сторонние официальные сайты; они
  открываются в браузере и помечены значком «online».

## Как поставить на телефон

1. Откройте адрес приложения в браузере.
2. **iPhone:** Safari → «Поделиться» → «На экран „Домой“».
   **Android:** Chrome → меню → «Установить приложение».

Дальше приложение открывается во весь экран и **без интернета**.

Вариант без хостинга: `dist/rc-planner.html` — один файл со всем внутри,
открывается двойным кликом откуда угодно.

## Разработка

```bash
npm run setup   # npm install + браузер для тестов (один раз)
npm run icons   # пересобрать иконки из SVG (нужен sharp)
npm run build   # public/ (PWA) и dist/rc-planner.html (офлайн-файл)
npm test        # пять наборов: данные, аудит экранов, офлайн-файл, PWA, вёрстка
npm run release # build + test
```

В рантайме зависимостей нет: vanilla HTML/CSS/JS, свой promise-wrapper над
IndexedDB (`db.js`). Справочный контент отделён от логики и лежит в `data/`.
Правила работы над проектом — в [`CLAUDE.md`](CLAUDE.md), планы — в [`ROADMAP.md`](ROADMAP.md).
