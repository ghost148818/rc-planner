# RC Planner — что дальше

MVP (выпуск 1) закрывает основной цикл: флот → чек-лист → полёт → журнал →
обслуживание → конфигурации → экспорт/импорт → PWA, полностью офлайн.

## Сделано после MVP

- ✅ **Окна для полётов** (v4): Open-Meteo без ключа, локация или GPS, ветер
  до 200 м, окна по порогу «Макс. ветер» модели, офлайн — честное сообщение.
- ✅ **Координаты локаций** (v4): GPS-кнопка, открытие на Яндекс.Картах/OSM.
- ✅ **Встроенная мини-карта локаций** (v0.10–0.13): тайлы OpenStreetMap
  по явному действию, выбор точки тапом; офлайн-режим приложения не страдает.
- ✅ **Статистика и регламент** (v1.3): налёт по месяцам, бортам и локациям,
  счётчик «осмотр каждые N полётов» с напоминанием на «Сегодня» и в чек-листе.
- ✅ **Экспорт журнала в CSV** (v1.3), фото повреждения в записи обслуживания.
- ✅ **Регламент по налёту** (v1.4): второй счётчик «осмотр каждые N минут
  налёта» рядом со счётчиком полётов; заданы оба — сработает тот, что
  подойдёт раньше.
- ✅ **Статистика в CSV** (v1.4): разделы экрана одной таблицей.
  Экран и выгрузка считаются из общего `statSections()` — разойтись не могут.

## Ближайшее

- **Фото в компонентах.** Снимок узла к записи компонента (у обслуживания
  фото уже есть). Отложено владельцем 2026-08-30.
- **Статистика глубже.** Разбивка по типам бортов, средняя длительность
  по локациям. Отложено владельцем 2026-08-30.

## Потом

- **AI-помощник (online, опционально, с явным согласием).** Анализ flight log,
  «я поменял ESC — что проверить перед вылетом», генерация чек-листа под модель.
  По умолчанию данные никуда не отправляются; перед каждым запросом — понятное
  предупреждение, какие именно данные уйдут внешнему сервису. В перспективе —
  локальная модель.
- **Firmware-журнал глубже.** Привязка версии прошивки к конфигурации,
  ссылки на release notes, напоминание «вышла новая версия» (online, опционально).
- **Синхронизация между устройствами** — только как отдельная опциональная
  функция (например, через файл в пользовательском облаке). Никакого
  обязательного сервера.

## Принципы, которые не меняются

- Офлайн — базовый режим, online — надстройка.
- Никаких аккаунтов, аналитики и рекламы.
- Данные пользователя принадлежат пользователю: экспорт всегда полный и читаемый.
- Вертолёты не планируются.
