# RC Planner — что дальше

MVP (выпуск 1) закрывает основной цикл: флот → чек-лист → полёт → журнал →
обслуживание → конфигурации → экспорт/импорт → PWA, полностью офлайн.

## Ближайшее

- **Погода (online, опционально).** Open-Meteo без ключа: выбор запомненной
  локации и даты, прогноз ветра/порывов/осадков до высоты 200 м и подсказка
  «окон», когда можно летать конкретной модели по её ТТХ (допустимый ветер
  задаётся в карточке модели). Без интернета — «Погода недоступна офлайн»,
  а не ошибка.
- **Фото в компонентах и обслуживании.** Снимок повреждения к записи ремонта.
- **Статистика.** Налёт по месяцам, по моделям, по локациям; счётчик «осмотр
  через N полётов» с автоматическим напоминанием в «Сегодня».
- **Экспорт журнала** в CSV для таблиц.

## Потом

- **AI-помощник (online, опционально, с явным согласием).** Анализ flight log,
  «я поменял ESC — что проверить перед вылетом», генерация чек-листа под модель.
  По умолчанию данные никуда не отправляются; перед каждым запросом — понятное
  предупреждение, какие именно данные уйдут внешнему сервису. В перспективе —
  локальная модель.
- **Firmware-журнал глубже.** Привязка версии прошивки к конфигурации,
  ссылки на release notes, напоминание «вышла новая версия» (online, опционально).
- **Синхронизация между устройствами** — только как отдельная опциональная
  функция (например, через файл в пользовательском облаке). Никакого
  обязательного сервера.

## Принципы, которые не меняются

- Офлайн — базовый режим, online — надстройка.
- Никаких аккаунтов, аналитики и рекламы.
- Данные пользователя принадлежат пользователю: экспорт всегда полный и читаемый.
- Вертолёты не планируются.
