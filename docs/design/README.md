# Дизайн-канвас RC Planner 2.0

Исходники дизайн-канваса «RC Planner 2.0».
Сам канвас опубликован как артефакт — ссылка в `docs/redesign-2.0.md`.

- `gen.mjs` — генератор артбордов: `node docs/design/gen.mjs` пишет
  `artboards/*.dc.html` и `artboards/canvas.json` (папка в `.gitignore`,
  всё воспроизводится из генератора).
- Скриншоты приложения с **посеянными** данными теперь пишет шестой
  тестовый набор `test/seeded.js` (`npm run test:seeded` →
  `test/shots/seeded/`; бывший `docs/design/shots.js`). Аудит гоняет
  пустую базу, на ней большинство экранов — пустые состояния; для
  проверки глазами нужны именно эти снимки — «Сегодня» во всех четырёх
  состояниях дня, тёмная и светлая темы, перчатки, десктоп. Наружу
  ничего не ходит: прогноз — поддельный кэш в settings.

Пересобрать канвас после правки: `node docs/design/gen.mjs`, затем
пересеять канвас из
`docs/design/artboards/`. Артборд «Сейчас» ссылается на четыре снимка
`cur-today/model/checklist/weather.png` версии 1.5 — исторические,
`test/seeded.js` их больше не пишет (экраны 1.5 из кода ушли). При
пересеве взять их из ветки 1.5 старым `docs/design/shots.js` или
подставить свежие `dark-today-home/model-overview/checklist/weather.png`
из `test/shots/seeded/`.

Тестовые данные экранов вбиты в `gen.mjs` строками; при правке следить,
чтобы полёты дня, время чек-листа, ветер часа и возраст копии сходились
между артбордами (второй взгляд 2026-09-01 ловил именно это).
